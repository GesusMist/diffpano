2. EXACT NEW GUIDANCE: COEFFICIENT NORMALIZATION ONLY

Suggested canonical mode name: poisson_mean_max.
Suggested independent parameter: gradient_mix_alpha.

Do not overload fusion.alpha (used by existing RGB/DPA behavior), lambda_color,
coarse_eta, or diffusion trajectory alpha coefficients.

For each current view prediction i, inverse-project RGB into the common ERP grid
using the existing warp. Let V_i be that contribution. For each oriented adjacent
pixel pair e=(p,q):

  d_i(e) = V_i(q) - V_i(p)  [signed RGB vector]
  a_i(p) = valid_mask_i(p) * existing_center_weight_i(p)
  s_i(e) = min(a_i(p), a_i(q))

Use the existing same-source endpoint support/validity rule. Invalid endpoints
must never create gradients or NaNs in valid output.

Accumulate the existing weighted mean gradient:

  g_mean(e) = sum_i s_i(e)*d_i(e) / sum_i s_i(e)

Select the existing magnitude-max gradient:

  i_max(e) = argmax_{i:s_i(e)>0} sum_c d_i,c(e)^2
  g_max(e) = d_i_max(e)

Use a stable camera-ID tie break. Copy the entire signed RGB vector from the
selected source, not per-channel maxima. Geometric confidence determines valid
support and mean weights; it must NOT multiply the max ranking or add a new gate.

Construct:

  g_alpha(e) = (1-alpha)*g_mean(e) + alpha*g_max(e)

Apply separately to existing horizontal and vertical edge fields. Alpha is one
fixed scalar for the entire run, all pixels, all denoising intervals, and terminal
fusion. It is the MAX coefficient:

  alpha=0.25 -> 75% mean + 25% max
  alpha=0.50 -> 50% mean + 50% max
  alpha=0.75 -> 25% mean + 75% max

"Normalized-coefficient" means these two coefficients sum to one. Do not use
unnormalized max+alpha*mean, per-edge unit-vector normalization, RMS capping,
contrast enhancement, per-image energy matching, magnitude rescaling, clipping,
softmax temperature, or adaptive alpha. Those are different experiments.

Compute both statistics from the SAME current source predictions in one
streaming pass. This mixes guidance BEFORE the Poisson solve, not two reconstructed
images, two final PNGs, or outputs of separate model trajectories.

Preserve the exact baseline weighted-RGB reference R, binary edge support M,
pixel-unit finite differences, periodic longitude and open vertical boundaries.
Keep accumulators and solves in FP32 outside autocast; FP64 is only for tiny
numerical reference tests. No clamp during generation. Keep memory O(BCHW) in
camera count; do not retain 89 full-resolution warped ERP contributions.

3. TWO REFERENCE OBJECTIVES, UNCHANGED EXCEPT FOR g_alpha

Define Egrad(I)=sum_e M(e)*||grad_e(I)-g_alpha(e)||_2^2.
R is the complete ordinary weighted-RGB fusion of the CURRENT proposals at the
current fusion stage, not a cached historical image or an unfinished accumulator.

lambda_blending / screened:
  minimize Egrad(I) + lambda_color*sum_p ||I(p)-R(p)||_2^2
  lambda_color = 0.1

coarse_color:
  minimize Egrad(I) + coarse_eta*sum_b n_b*||B_b(I)-B_b(R)||_2^2
  subject to avg_hw(I)=avg_hw(R) separately per image and RGB channel
  coarse_eta = 0.1
  coarse grid = 16 rows x 32 columns of nonoverlapping blocks
  B_b is block-average RGB; n_b is the number of pixels in block b.

RGB penalty to coarse_color or otherwise modify the objectives.
