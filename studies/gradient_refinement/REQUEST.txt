## 4. Four precise reference modes

### A. `screened` — current behavior

Minimize:

`Egrad(I) + 0.1 * sum_p ||I(p) - R(p)||_2^2`.

Keep the established implementation and default numerical behavior for backward compatibility. Do not silently change its objective, boundary handling, or normalization while adding other modes.

### B. `global_mean` — only three global RGB constraints

Minimize `Egrad(I)`, subject to:

`mu(I) = mu(R)`,

independently for each image and RGB channel.

`mu` is the ordinary arithmetic mean over ERP pixels, matching the current discrete formulation. This constrains three numbers per image; it is not a per-pixel attraction to R.

Use explicit nullspace handling. On a connected supported-edge graph, solve for a zero-mean least-squares reconstruction J and return:

`I = J + mu(R)`.

Do not approximate pure Poisson by retaining a small positive screening coefficient.

### C. `single_pixel` — one source-patch center reference

Minimize `Egrad(I)`, subject to:

`I(p0) = c0`.

Use a deterministic source patch, not a fresh random choice at each step. For this fixed-camera study, select the camera whose optical axis is closest to yaw 0, pitch 0; break ties by stable camera ID and retain that ID throughout the run. Expose an explicit override if useful, but do not sweep it.

Find a valid ERP pixel p0 corresponding to the center of that patch. Obtain c0 from that **same source’s floating-point prediction at that same ERP ray**, using the existing projection/sampling convention. A nearby ERP pixel sampled from the source’s warped contribution avoids mismatching an exact source-center color with a different ERP ray.

Do not take c0 from R, a PNG, an initial noisy image, or another view.

Use the current clean proposal’s c0 at each coupled fusion and the terminal proposal’s c0 at final fusion. Fix the source identity and geometric selection rule, not the RGB value across denoising.

For a connected graph, use the same zero-mean gradient-only solution J and return:

`I = J + c0 - J(p0)`.

Record camera ID, source/ERP coordinates, current c0, output anchor error, and any deterministic mapping fallback. If this anchor option is used with dynamic geometry later, preserve a reproducible source-selection rule and map the actual current camera; never change the camera schedule just to maintain an anchor.

For identical proposals and g, `global_mean` and `single_pixel` must yield identical gradients before clipping, differing only by a constant RGB offset. Their complete generation trajectories can diverge after subsequent nonlinear model/encoder operations, so both remain separate experiments.

### D. `coarse_color` — only coarse spatial color guidance

Use a fixed **16×32 grid of nonoverlapping ERP blocks**. At 2048×4096, each block is 128×128 pixels. Let `B_b(X)` be the mean RGB of block b and `n_b` its pixel count.

Minimize:

`Egrad(I) + eta * sum_b n_b * ||B_b(I - R)||_2^2`,

with `eta=0.1`.

Also enforce `mu(I)=mu(R)` explicitly for a stable common convention; this is compatible with the weighted coarse penalty.

There must be no additional full-resolution `||I-R||^2` penalty in this mode. Within-block zero-mean changes are unpenalized by the color term. The `n_b` factor is intentional: it prevents the same numeric coefficient becoming negligible merely because the coarse image contains fewer pixels.

Expose coarse grid dimensions and eta, but freeze them to **16×32 and 0.1** for all cases in this study. Document these as initial ablation choices, not tuned optimum values.

Implement B and its true weighted adjoint. Arbitrary bilinear upsampling is not the adjoint of block averaging. Use exact nonoverlapping partitions, or validate divisibility for the selected configuration. Do not replace this with an invertible full-resolution blur equality.

## 6. Two gradient modes

### `poisson_select`

Preserve the existing rule exactly. For an oriented ERP edge e=(p,q), use the existing edge confidence `s_i(e)`, currently based on the minimum endpoint confidence.

Select the valid source with largest `s_i(e)`, with the existing stable-ID tie break, and copy its signed RGB difference.

### `poisson_max`

For each oriented ERP edge, compute:

`d_i(e) = V_i(q) - V_i(p)`,

**after the same perspective-to-ERP RGB warp** used by the existing implementation.

Among sources valid at both endpoints under the existing support rule, select:

`i* = argmax_i ||d_i(e)||_2`,

where the norm is over the three RGB channels.

Set `g(e)=d_i*(e)`, copying the entire signed RGB vector. Apply this independently to the existing horizontal and vertical edge fields.

Do not:

- Take componentwise numeric maxima.
- Drop gradient signs or select RGB channels from different views.
- Multiply the magnitude ranking by geometric confidence.
- Add a new confidence gate beyond the existing validity/support rule.
- Add mean guidance or contrast amplification.
- Attempt to derive source-wise max from already-aggregated mean/select fields.

Use stable camera-ID tie handling, including ties at zero magnitude. Keep streaming O(BCHW) statistics instead of retaining all warped ERP views.
