# Seed-0 panorama evaluation

Read-only scoring of benchmark210, camera48 (old89 reuses24 benchmark images), and42 FLUX step controls. The refresh adds126 camera-count rows (120 complete, six blocked), for426 logical outputs. Nine unfinished FLUX controls remain cancelled. Outputs, metrics, evidence and compact caches are under `outputs/metrics-evaluation/seed0-v1/`. The existing outputs symlink remains unchanged.

`python3 -m studies.panorama_metrics.launch` is a nonblocking, idempotent submit command from the repository root. It checks the validated source freeze, prevents overlapping evaluator GPUs, and submits one finite pass; it never submits generation. The updater verifies new completion pairs/provenance/accounting, skips valid content/checkpoint/protocol caches, and refreshes matched-prompt reports. A final update uses `--follow-generation JOB` and afterany dependencies so failed generation cases remain visible. No polling service.

Initial jobs: CPU image/provenance/seam validation and scoring; generated GPU CLIP/Inception features; then one GPU for real reference features; CPU collection aggregation; incremental GPU update. Up to four generation GPUs plus one evaluator. All numerical/rendering/model work runs in Slurm, not on login nodes.

The isolated evaluation environment is `/scratch/user/shig/diffpano/evaluation-env`, activated through `environment.sh` with the existing system Torch module. Its pinned environment, upstream revisions and asset checksums are saved alongside reports/assets; no generation environment was changed.

Protocol details are in metric_protocols.json: common eight90-degree horizontal512-square views, separate polar CLIP diagnostics, native4K ERP DS, ERP-derived cubemap seam adaptations, and the separate OmniFID protocol averaging four horizontal feature vectors within each panorama before Frechet statistics. CLIP is100 times raw cosine; long prompts use all tokens in fixed75-payload-token chunks. No rotations, repairs or generated references.

The entire released SUN360 test split (4260 panoramas) was fixed independently of scores, hashed individually and used identically for every group. Mixed real photographs differ from the21 stylized/custom prompts. Distribution scores are exploratory, with effective panorama/view counts and covariance rank limits. KID uses100 subsets, raw unbiased polynomial MMD squared, seed2020. IS uses one full collection split. FID retains2048 dimensions even for singular covariances. Prompt bootstrap intervals apply to per-panorama paired scores, never independent crops or three-prompt camera significance.

FAED remains blocked by HTTP403 from the released checkpoint link. Distort-FID remains blocked by the unreleased trained evaluator/checkpoint. DS follows the linked survey code's first-order Scharr, whereas the paper describes second-order Scharr and original code is unreleased; it is explicitly labeled as an adaptation. Cubemap seam metrics also document unreleased-code details and ERP-derived limitations. Missing metrics are blank with statuses, never fake zeros.
